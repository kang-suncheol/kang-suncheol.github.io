# 전자전 스펙트럼 아틀라스

전자전의 개념, LIG D&A(옛 LIG넥스원)의 영역별 전자전 사업과 핵심기술, 2026년 하반기 세계 전자전 이슈, 미래 전략을 공개자료로 정리한 웹사이트입니다.

## 구성

| 페이지 | 내용 |
|---|---|
| 01 전자전이란 | 전자전 지원(ES)·전자 공격(EA)·전자 보호(EP), 2026년 주요 수치 |
| 02 영역별 사업 | 우주·항공·지상·해양·수중 영역별 사업 이력 |
| 03 핵심기술 | 기술 × 영역 매트릭스 |
| 04 세계 이슈 | 2026년 7~10월 세계 전자전 이슈 지구본 |
| 05 LIG D&A 이슈 | 사업·경영·리스크 타임라인 |
| 06 미래 전략 | 영역 통합과 우주 확장 로드맵 |
| 07 출처 | 출처 목록과 미확인 항목 |

## 참고

- 모든 내용은 공개자료 기준이며, 조사 기준일은 2026년 10월 18일입니다.
- 회사 공식 자료가 아닙니다.
- 단일 HTML 파일(`index.html`)이며 외부 라이브러리 없이 동작합니다.
